# 配置用 JSON 文件存储，不用数据库

配置（分组结构、单应用设置、全局设置）存在 `~/Library/Application Support/AppBox/` 下的 JSON 文件中，一个方案对应一个文件；图标缓存放在同目录的子文件夹，不进配置文件。

理由：配置数据量只有几十 KB，SQLite 的查询与事务能力用不上；纯文本 JSON 人类可读、可手改、可单独拷走备份，且「一个方案一个文件」天然满足多方案切换的需求。

后果：每次变更全量读写整个 JSON（数据量小，无性能影响）；需要自己实现 schema 版本号与迁移逻辑，因为 Swift 的 `Codable` 在字段变更时会直接解码失败。
