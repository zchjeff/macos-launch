# 只做全局快捷键唤起，不接管触控板捏合手势

用 Carbon 的 `RegisterEventHotKey` 注册全局热键（默认 ⌥+Space，控制台可改）唤起覆盖层。不实现原版 Launchpad 的触控板捏合手势。

理由：捏合手势在原版中由 Dock.app 通过私有 API 实现，第三方应用只能靠 `CGEventTap` 监听，需要用户手动授予「辅助功能」权限，且手势事件可能被 Dock 或系统抢占而失效——属于「能用但不保证」的脆弱方案。全局热键零权限、系统级稳定。

后果：AppBox 的权限需求保持在最小集合（不需要辅助功能权限）；想要手势体验的用户需自行寻找其他工具。
