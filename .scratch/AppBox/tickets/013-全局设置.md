# 全局设置

**Blocked by**: 002, 010

## 目标

控制台里的设置页：改热键、调网格与图标尺寸、调背景模糊度、开关系统应用、开关开机自启、退出应用。

## 涉及层

- [ ] 数据层：配置中 `hotkey` / `gridColumns` / `gridRows` / `iconSize` / `blurRadius` / `includeSystemApps` / `launchAtLogin` 字段
- [ ] 逻辑层：热键重新注册、开机自启的 LaunchAgent 写入与移除、含系统应用开关触发的重新扫描
- [ ] UI层：设置页各控件、热键录制控件、退出按钮
- [ ] 测试：设置持久化与生效的单元测试；热键注册与 LaunchAgent 走手工验证

## 验收标准

- 能修改唤起热键：控件能录制新的组合键，修改后旧热键立即失效、新热键立即生效，无需重启
- 热键录制拒绝无效组合（如只有修饰键没有主键），并给出提示
- 能调整网格列数、行数、图标尺寸，覆盖层立即按新值排版
- 能调整覆盖层背景模糊度，视觉立即生效
- 关闭「包含系统应用」后，`/System/Applications` 下的应用从覆盖层消失（但配置保留，重新打开后恢复）
- 关闭「包含系统应用」时，若某些系统应用已被归入自定义分组，需给出提示说明它们将暂时隐藏
- 能开关开机自启；开启后写入 LaunchAgent，关闭后移除
- 开机自启开关的状态与实际系统状态一致（不出现"开关是开的但实际没生效"）
- 能从控制台退出 AppBox，退出后热键失效、进程无残留
- 所有设置持久化，重启保持
- 单元测试：设置项读写与快照重算

## 备注

- 开机自启默认**开启**（否则热键不生效，应用形同不存在）
- 修改热键时需要先注销旧热键再注册新的，注册失败要回滚到旧热键并提示，不能出现"两个热键都失效"的状态
