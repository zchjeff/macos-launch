# 单应用管理 + 失效列表

**Blocked by**: 010

## 目标

在控制台里对单个应用做展示层调整：改别名、隐藏、锁定位置、指定排序权重；并能看到「失效」应用列表并手动清理。

## 涉及层

- [ ] 数据层：配置中每个应用的 `alias` / `hidden` / `locked` / `orderWeight` 字段
- [ ] 逻辑层：设置与清除别名、隐藏与恢复、锁定后不参与自动排序、排序权重生效；失效记录查询与清理
- [ ] UI层：应用详情面板、各操作的开关与输入、失效列表视图与清理入口
- [ ] 测试：各项操作的单元测试 + 快照组装时别名/隐藏/排序生效的断言

## 验收标准

- 设置别名后，覆盖层与该应用所在的分组方块缩略图都显示别名
- 别名可清除，清除后恢复真实名称
- 隐藏应用后，它从覆盖层消失（含分组方块缩略图），但控制台里仍可见并可恢复
- 隐藏不影响应用在系统中正常运行
- 锁定位置后，该应用在所属分组内不被自动排序挤走
- 排序权重生效：分组内应用按权重排序，未指定权重的按名称排
- 应用详情显示：真实名称、bundleID、最近已知路径、所属分组、是否隐藏、是否锁定、是否失效
- 「失效」列表显示所有"配置有、磁盘上找不到"的应用
- 可从失效列表中清理单条记录；清理后该应用的别名/分组/隐藏配置一并移除
- 失效应用不出现在覆盖层的任何位置
- 单元测试：设置/清除别名、隐藏/恢复、锁定、权重排序、失效判定与清理

- 本切片只做"失效列表 + 手动清理"，**自动标记失效**依赖 014 的增量同步
