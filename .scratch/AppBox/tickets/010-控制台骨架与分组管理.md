# 控制台窗口骨架 + 分组管理

**Blocked by**: 006

## 目标

点击 Dock 图标打开控制台窗口，在其中新建/重命名/删除/排序分组，并把应用拖进拖出分组。这是「归纳整理」真正发生的地方。

## 涉及层

- [ ] 数据层：无新增（复用 006 的分组模型）
- [ ] 逻辑层：控制台视图模型，全部变更经 `LibraryService`
- [ ] UI层：控制台窗口（独立常规 `NSWindow`）、左侧分组列表 + 右侧应用列表、增删改排序交互、拖拽移入移出
- [ ] 测试：分组操作的单元测试已在 006 覆盖；本切片补 UI 动作到 `LibraryService` 调用的映射测试

## 验收标准

- 点击 Dock 图标打开控制台窗口（不是覆盖层）
- 应用启动时（非首次）只静默常驻，不自动弹控制台；首启行为见 015
- 控制台左侧列出所有分组（含「未分类」），右侧显示选中分组的应用
- 能新建分组、重命名分组、删除分组
- 「未分类」在界面上不可删除、不可重命名（按钮禁用或隐藏，而非点了报错）
- 删除分组前弹出确认，明确告知"组内 N 个应用将移入未分类"
- 能拖拽调整分组顺序
- 能把应用从右侧列表拖到左侧某个分组上完成移入
- 能在右侧列表中调整应用顺序（顺序写入排序权重）
- 所有变更立即持久化，重启 AppBox 后保持
- 空分组在列表中保留，不自动消失
- 控制台关闭后应用继续常驻，热键仍可用

## 备注

- 控制台是配置的**唯一写入场所**（覆盖层内拖拽除外，见 012）
- 控制台不做卸载、不做自定义图标（ADR-0004、spec 明确不做）
