# 【示踪弹】覆盖层显示真实应用 + 单击启动收起

**Blocked by**: 002, 003

## 目标

按 ⌥+Space 唤起覆盖层，看到的是**磁盘上真实的应用**，单击任一图标能启动它并自动收起覆盖层。这是第一条端到端打通的路径，证明整个架构成立。

## 涉及层

- [ ] 数据层：`LibraryService` 门面 + `LibrarySnapshot`（渲染就绪的扁平应用列表）；注入端口 `AppScanning` / `IconProviding` / `Launching`
- [ ] 逻辑层：扫描结果与配置合并为快照；隐藏的应用不进快照
- [ ] UI层：覆盖层网格渲染真实图标与显示名；单击启动；启动后收起
- [ ] 测试：`LibraryService` 快照组装的单元测试，用假端口注入

## 验收标准

- 覆盖层网格显示真实应用的图标与名称，排版与数量正确
- 图标来自 003 的磁盘缓存，唤起时无可见的加载卡顿
- 单击图标能启动对应应用
- 启动后覆盖层自动收起
- 应用已在运行时，单击**激活已有实例**，不新开一个实例
- 别名未设置时显示应用真实名称
- 单元测试：假扫描器喂 fixture，断言 `LibrarySnapshot` 的应用列表、主键、排序
- 单元测试：`Launching` 假实现能断言"被调用的 bundleID 与点击的一致"
- 从按键到覆盖层可见的延迟 < 150ms（spec H1，图标已缓存的前提下）

## 备注

- 这是最胖的一颗示踪弹，一次打穿 6 层：文件系统 → 扫描 → 领域 → 图标 → UI → 启动
- 此切片还不涉及分组（所有应用平铺）、不涉及配置持久化、不涉及搜索与键盘导航
