# 覆盖层内拖拽整理

**Blocked by**: 007

## 目标

不打开控制台，直接在覆盖层里拖拽整理：调整组内顺序、把应用拖进分组方块、把应用拖出分组、调整分组方块顺序。

## 涉及层

- [ ] 数据层：无新增（复用 `LibraryService` 的移动与排序操作）
- [ ] 逻辑层：拖拽的落点判定（落在图标上 = 排序，落在分组方块上 = 移入）
- [ ] UI层：拖拽手势、拖拽预览、落点高亮、文件夹方块作为放置目标的视觉反馈
- [ ] 测试：落点判定逻辑的单元测试

## 验收标准

- 在分组子网格内拖拽应用，可改变组内顺序，松手后立即持久化
- 在顶层把应用拖到分组方块上，该应用移入该组（方块给出明确的接收反馈）
- 在分组子网格内把应用拖到空白区域，该应用移回「未分类」
- 在顶层拖拽分组方块，可调整分组顺序
- 拖拽到非法落点（如把分组方块拖到另一个分组方块上）时，操作被拒绝且不改变任何数据
- 拖拽过程中按 Esc 取消，不改变任何数据
- 拖拽结果与在控制台中做同样操作的结果一致（同一套 `LibraryService` 操作）
- 拖拽完成后配置立即持久化，重启保持
- 单元测试：落点判定在各种位置组合下的结果

## 备注

- 本切片与 010 的控制台拖拽是两条 UI 路径，但落到同一套领域操作上——这是刻意的，保证两条路径不会产生不一致
- 拖拽到分组方块上时**不做**原版 Launchpad 的"展开动画预览"，只做简单的接收高亮
