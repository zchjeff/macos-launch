# 搜索框 + 拼音首字母匹配

**Blocked by**: 006

## 目标

覆盖层顶部一个输入框，输入即实时筛选，支持中文名、英文名、别名、拼音首字母（打 `wx` 能筛出微信 / WeChat）。结果显示为平铺列表，不分组。

## 涉及层

- [ ] 数据层：无（复用快照）
- [ ] 逻辑层：多字段匹配（真实名、别名、bundleID）、拼音首字母生成与匹配、大小写不敏感
- [ ] UI层：搜索框、实时筛选、平铺结果列表、无结果空态
- [ ] 测试：匹配逻辑的单元测试，覆盖中文/英文/别名/拼音/大小写/无结果

## 涉及层补充

拼音匹配需要一份汉字到拼音首字母的映射。**不引入第三方依赖**（ADR-0001 的极简取向），用系统自带的 `CFStringTransform` 或 `StringTransform.toLatin` 做汉字转拼音，取每个音节首字母。

## 验收标准

- 覆盖层唤起后直接输入字符，搜索框自动获得焦点并接收输入（不需要先点搜索框）
- 输入即实时筛选，无需回车
- 匹配范围是**全部应用**（跨分组），不受当前所在分组影响
- 结果以平铺列表显示，**不分组**
- 匹配字段：真实名称、别名、bundleID
- 大小写不敏感
- 拼音首字母匹配：`wx` 能匹配到「微信」和「WeChat」；`vscode` 能匹配到「Visual Studio Code」（同时支持整词前缀与首字母两种路径）
- 无结果时显示明确的空态提示，不显示空白网格
- 清空搜索框后回到原来的网格视图（保留之前所在的分组层级）
- 搜索结果中单击图标能启动应用并收起覆盖层
- 搜索结果中方向键 + Enter 可用
- 单元测试：中文名精确/前缀匹配、英文名大小写、别名匹配、拼音首字母、bundleID 匹配、无结果、空查询

## 备注

- 与 008 的"按字母跳转高亮"分工：一旦用户在覆盖层输入字符，走搜索筛选（本切片）；008 的按字母跳转仅在搜索框未激活时生效
